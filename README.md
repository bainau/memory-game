# The Forgotten Library — Memory Game

A browser-based memory game with a mysterious forgotten library theme.

## Description

The game contains 16 cards forming 8 matching pairs. Players turn over two cards at a time and try to find all matching pairs with as few moves as possible.

The game includes:

* shuffled cards on every new game;
* moves and pairs counters;
* animated card flipping;
* a short delay for unmatched cards;
* victory modal;
* leaderboard with the 10 best results;
* results saved in `localStorage`;
* responsive layout for desktop, tablet, and mobile screens.

## How to run

Open `index.html` in a web browser.
